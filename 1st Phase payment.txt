| 3. Validate địa chỉ | `UserService.getAddressById()` | `user.service.ts` |

## BƯỚC 5: XỬ LÝ THANH TOÁN (TÙY PAYMENT METHOD)

### A. WALLET (Ví điện tử)
| Bước | Class/Hàm |
|------|-----------|
| 1. Check số dư | `WalletService.getMyWallet()` |
| 2. Trừ tiền ví | `WalletService.debitForOrder()` |
| 3. Tạo escrow giữ tiền | `EscrowService.createHold()` |
| 4. Đánh dấu đã thanh toán | `Order.markAsPaid()` |

**DB tham gia:**
| Table | Thuộc tính |
|-------|------------|
| `wallets` | `availableBalance` (trừ đi) |
| `wallet_transactions` | Tạo record giao dịch |
| `escrows` | `orderId`, `shopId`, `amount`, `status=HOLDING` |
| `orders` | `paymentStatus=PAID`, `paidAt` |

### B. VNPAY
| Bước | Class/Hàm |
|------|-----------|
| 1. Tạo payment transaction | `PaymentService.createOrderPayment()` |
| 2. Tạo VNPay URL | `VnpayService.createPaymentUrl()` |
| 3. Trả về URL | Response chứa `paymentUrl` |

**DB tham gia:**
| Table | Thuộc tính |
|-------|------------|
| `payment_transactions` | `id`, `orderId`, `amount`, `vnpayTxnRef`, `type=ORDER_PAYMENT`, `status=PENDING` |
| `orders` | `status=PENDING`, `paymentStatus=PENDING` |

### C. WALLET_VNPAY (Ví + VNPay)
Kết hợp A + B: Trừ ví trước, phần còn lại qua VNPay

### D. COD (Thanh toán khi nhận hàng)
| Bước | Class/Hàm |
|------|-----------|
| 1. Confirm order ngay | `Order.confirm()` |
| 2. Lưu order | `OrderRepository.save()` |

**DB tham gia:**
| Table | Thuộc tính |
|-------|------------|
| `orders` | `status=CONFIRMED`, `confirmedAt` |

## BƯỚC 6: BACKEND TRẢ VỀ RESPONSE

### Cấu trúc data trả về
```typescript
// CreateOrderResponse
{
  orders: [{
    id: string,
    orderCode: string,        // VD: "#ORD123456"
    status: 'pending' | 'confirmed',
    paymentMethod: string,
    paymentStatus: 'pending' | 'paid',
    receiverName, receiverPhone, shippingAddress,
    subtotal, shippingFee, platformFee,
    tierDiscountAmount, voucherDiscountAmount,
    coinUsed, totalAmount, coinEarned,
    buyerNote, shopNote,
    shop: { id, name, slug, logoUrl },
    items: [{
      id, productId, variantId,
      productName, variantName, productImageUrl,
      unitPrice, quantity, totalPrice
    }],
    createdAt, updatedAt
  }],
  paymentUrl?: string,        // Chỉ có nếu VNPAY/WALLET_VNPAY
  txnRef?: string,            // Transaction reference
  walletAmountUsed?: number,  // Số tiền trừ từ ví
  vnpayAmount?: number        // Số tiền qua VNPay
}
```

## BƯỚC 7: FRONTEND XỬ LÝ RESPONSE

### Trong `checkout/page.tsx` - hàm `handleSubmit()`
```typescript
if (response.paymentUrl) {
  // VNPay: Redirect sang trang thanh toán VNPay
  window.location.href = response.paymentUrl;
  return;
}

// Wallet/COD: Navigate đến trang success
const orderIds = response.orders.map((o) => o.id).join(',');
router.push(`/checkout/success?orders=${orderIds}`);
```

## BƯỚC 8: HIỂN THỊ KẾT QUẢ

### A. Nếu VNPAY - Redirect đến VNPay Gateway
- User thanh toán trên VNPay
- VNPay redirect về: `GET /payments/vnpay/return`
- Backend xử lý: `PaymentController.handleVnpayReturn()`
- Redirect về FE: `/checkout/success?status=success`

### B. Nếu Wallet/COD - Trang Success

| Tiêu chí | Chi tiết |
|----------|----------|
| **Page** | `frontend/src/app/(main)/checkout/success/page.tsx` |
| **Lấy order IDs** | `searchParams.get('orders')?.split(',')` |

## TỔNG KẾT TRẠNG THÁI ĐƠN HÀNG SAU TẠO

| Payment Method | Order Status | Payment Status |
|----------------|--------------|----------------|
| WALLET | `pending` | `paid` |
| VNPAY (chưa thanh toán) | `pending` | `pending` |
| VNPAY (đã thanh toán) | `pending` | `paid` |
| WALLET_VNPAY | `pending` | `pending/paid` |
| COD | `confirmed` | `pending` |

**Đơn hàng giờ đây chờ shop xác nhận (với COD đã tự động confirm).**
